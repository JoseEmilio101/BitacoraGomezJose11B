IRTRA SafeZone

Sistema inteligente de detección y alerta para zonas restringidas

IRTRA SafeZone es una propuesta tecnológica diseñada para mejorar la seguridad en áreas restringidas o de riesgo mediante sensores de movimiento, señales luminosas y alertas sonoras.

Conocer el proyecto

Problemática

Acceso a zonas restringidas

Algunas áreas pueden representar un riesgo para los visitantes si ingresan sin autorización.

Falta de detección inmediata

Una persona que ingrese a una zona restringida puede no ser detectada inmediatamente.

Necesidad de prevención

Un sistema automático puede ayudar a advertir rápidamente cuando se detecta movimiento.

Objetivos

  • Diseñar un sistema capaz de detectar movimiento en una zona determinada.
  • Implementar señales luminosas mediante LEDs para indicar diferentes estados del sistema.
  • Incorporar una alerta sonora mediante un buzzer.
  • Utilizar Arduino como unidad principal de control.
  • Crear un prototipo funcional que permita demostrar el funcionamiento del sistema.

Funcionamiento del sistema

IRTRA SafeZone utiliza diferentes componentes electrónicos que trabajan en conjunto para detectar movimiento y generar una respuesta visual y sonora.

1

Detección

El sensor PIR detecta movimiento dentro del área protegida.

2

Procesamiento

Arduino recibe la señal del sensor y determina qué acción debe realizar.

3

Alerta visual

Los LEDs muestran el estado correspondiente del sistema.

4

Alerta sonora

El buzzer emite una señal de advertencia cuando se detecta una situación determinada.
